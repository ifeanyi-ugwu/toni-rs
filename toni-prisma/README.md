# toni-prisma

Prisma integration for the [Toni framework](https://github.com/monterxto/toni-rs).

Registers a `prisma-client-rust` generated client in Toni's DI container so any injectable can declare it as a dependency.

Unlike the other database integrations, the Prisma client is **generated per project** — there is no universal `PrismaClient` type. `PrismaModule::for_root` accepts a closure that produces your generated client and registers it under its concrete type token.

## Prerequisites

Add `prisma-client-rust` and the CLI to your project following the [official setup guide](https://prisma.brendonovich.dev/getting-started/setup), then run:

```sh
cargo prisma generate
```

This generates a `db` module (or whatever name you configured) containing your `PrismaClient`.

## Installation

```toml
[dependencies]
toni-prisma = "0.1"
```

## Setup

Pass a closure to `PrismaModule::for_root` that connects your generated client. The client becomes available to every module in the application without further imports.

```rust
use toni_prisma::PrismaModule;

#[module(imports: [PrismaModule::for_root(|| db::new_client())])]
pub struct AppModule;
```

`db::new_client()` is generated by `prisma-client-rust` and returns a `Future<Output = PrismaClient>`. The closure is called once during application startup.

## Injecting the client

Declare the generated client as a field in any injectable:

```rust
use db::PrismaClient;

#[injectable]
pub struct UserService {
    #[inject]
    db: PrismaClient,
}

impl UserService {
    pub async fn find_all(&self) -> Vec<db::user::Data> {
        self.db.user().find_many(vec![]).exec().await.unwrap()
    }

    pub async fn find_by_id(&self, id: String) -> Option<db::user::Data> {
        self.db
            .user()
            .find_unique(db::user::id::equals(id))
            .exec()
            .await
            .unwrap()
    }
}
```

The generated `PrismaClient` type must implement `Clone`. `prisma-client-rust` clients are `Clone` by default.

## Error handling

If the connection closure returns a `Result`, unwrap or handle it before returning:

```rust
PrismaModule::for_root(|| async {
    db::new_client().await.expect("failed to connect to database")
})
```
